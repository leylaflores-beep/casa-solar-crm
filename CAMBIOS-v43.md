# Casa Solar CRM v43

## Calculadora de costos de calentadores

- Se agregó al menú la opción **Calculadora de costos** con un ícono monetario propio.
- El modelo del calentador y el precio base se escriben manualmente.
- Distribución inicial: Tanque 50%, Tubos 35% y Estructura 15%.
- Los nombres y porcentajes de las partes pueden modificarse.
- El valor de cada componente se calcula automáticamente sobre el precio ingresado.
- El sistema muestra una advertencia cuando los porcentajes no suman 100%.
- Permite agregar Flete / Electroválvula, Filtro y Otros costos.
- Muestra subtotal de partes y costo total calculado.
- Los valores se guardan automáticamente en el dispositivo.
- Incluye un botón para restablecer el ejemplo CSG15.

## Ejemplo incluido

Con un valor de Q5,975:

- Tanque 50%: Q2,987.50.
- Tubos 35%: Q2,091.25.
- Estructura 15%: Q896.25.
- Total de partes: Q5,975.00.

## Validación

- Compilación de producción verificada con Vite.
