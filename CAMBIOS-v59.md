# Casa Solar CRM v59

## Calculadora de estructuras

- Nueva calculadora guiada para costanera, nivelación, elevación de calentadores y elevación de depósitos de agua.
- Carga automáticamente cantidades y costos iniciales de materiales a partir de los Excel proporcionados.
- Permite editar cantidades, precios unitarios, mano de obra, transporte, herramienta, IVA, comisión y utilidad.
- Calcula materiales, costo directo y precio sugerido de venta.
- Guarda el borrador automáticamente en el dispositivo.
- Acceso exclusivo para usuarios con rol **Jefe** y para Samuel Lemus.
- Incluye el tipo de techo como verificación y una advertencia de validación técnica antes de fabricar o instalar.

## Instalación en GitHub

1. Abra la carpeta `src` del repositorio.
2. Reemplace `CasaSolarCRM.jsx` y `Campaigns.jsx` por los incluidos en esta actualización.
3. No coloque estos archivos en la raíz del repositorio.
4. Espere a que las acciones de publicación terminen con marca verde.
5. Abra el CRM en una ventana privada o borre la caché para verificar la versión v59.
