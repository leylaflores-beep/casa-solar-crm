# Casa Solar CRM v74

- Se eliminó la repetición visual del nombre del producto en el formulario de cotización.
- La descripción adicional queda vacía y es opcional; se utiliza solo para modelo, marca o características especiales.
- El CRM elimina automáticamente opciones duplicadas que coincidan entre el catálogo base y el Kardex importado.
- Las cotizaciones existentes no se borran ni se modifican.
- Se conservan las visitas técnicas y todas las mejoras de la versión v73.
