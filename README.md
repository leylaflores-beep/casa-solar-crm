# CRM Multiservicios Flores
CRM independiente conectado al proyecto Firebase crm-multiservicios-flores.

## Publicación
1. Subir el contenido de esta carpeta al repositorio crm-multiservicios-flores.
2. Vincular el repositorio desde Firebase Hosting.
3. Seleccionar npm run build y carpeta de salida dist.

La información se guarda en Cloud Firestore y el ingreso utiliza Firebase Authentication.
